Lounge photos belong in <lounge-id>/filename.webp (or AVIF/JPEG/PNG).

Use owner-supplied or explicitly licensed images, ideally around 1200 pixels wide.
Reference /lounges/<lounge-id>/filename.webp from the airport JSON with alt text,
credit, license and sourceUrl. Do not add full-size originals or unlicensed images.

The data editing guide is data/lounges/README.md in the source repository.
